# Ajour MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let agents such as Claude Code and Codex read and change Ajour's timers, entries and backlog through an MCP endpoint in the local API, report their work in sessions, ask the user questions, and show all of it in a corner indicator.

**Architecture:** The local API serves MCP over Streamable HTTP at `/mcp/ajour`, authenticated by per-client bearer tokens. The API forwards every data tool to the renderer over a server-sent event stream (`/api/mcp/bridge`), because the renderer owns all data. The renderer runs each call through the object action sets and the existing store commands, and posts the result back. Sessions, questions, activity and errors live in API memory and reach the renderer as snapshots on the same stream.

**Tech Stack:** Node `http` + `@modelcontextprotocol/sdk` 1.32 (API), zod 3.25 (shared contracts), React 19 + TanStack Router + Base UI toasts (web), vitest, Playwright + playwright-bdd (acceptance).

**Spec:** `docs/superpowers/specs/2026-10-14-ajour-mcp-design.md` and `agents/adr/0004-mcp-sends-local-data-to-the-clients-model.md`. Read both before starting.

## Global Constraints

- MCP is off by default. When off, every `/mcp/*` path answers 404 and the bridge answers 404.
- The API keeps its loopback binding and Host check.
- `/mcp/*` requires `Authorization: Bearer <token>`. Missing, unknown or revoked token: 401. Any request to `/mcp/*` with an `Origin` header: 403.
- Ajour stores only the SHA-256 hash of a token, in `app-api-state.json`. The token appears once, in the create response.
- Bridge messages, verbatim: "Open the Ajour window to use this tool." and "Ajour did not answer in time." The bridge timeout is 10 seconds.
- Session deadline: the estimate plus 25%, at least 2 minutes, at most 4 hours.
- `wait_for_answer` holds a call at most 50 seconds.
- The activity list keeps the last 200 events. It never keeps notes or tool inputs.
- Undo toast title for an agent write: `<Client name>: <action>`.
- No Delete or Discard tools.
- Wide events: `mcp.request` and `mcp.session_ended`. Never log tool inputs, answers or notes.
- Dependency direction: `domain` stays pure (no React, `lib` or `features`). `lib` never imports `features`. Code outside `packages/shared` imports only its root files.
- Use `just` for full runs (`just test`, `just typecheck`, `just acceptance-test`). Focused runs use `corepack pnpm --filter <package> exec vitest run <file>`.
- Conventional commits, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- English everywhere. Match the comment density and idiom of the file you edit.

## Decisions this plan adds to the spec

The spec is approved. These four points refine it where the code forced a choice. The plan follows them.

1. The tool runner lives in `apps/web/src/features/agents/`, not `lib/agent-tools.ts`. It needs `canWriteToSource` from `features/backlog`, and `lib` may not import `features`.
2. Revoking a client keeps its record with `revokedAt`, instead of deleting the hash, so the 401 error can name the client.
3. In v1, agents cannot settle or move a synced item that writes its state to its source. Those flows open dialogs (source state choice). The tool refuses with a sentence telling the agent to ask the user.
4. Acceptance tests stub the local API with `page.route`, as every existing feature does. The real MCP client runs against the real API in `apps/api/src/mcp-server.test.ts`.

## Review Focus

1. **A second window or a reload opens a second bridge.** The newer stream replaces the older one, and calls sent on the old stream time out. Test: Task 3, "a second bridge replaces the first".
2. **MCP is turned off while an agent is connected.** The bridge stream ends and `/mcp/ajour` answers 404 at once. Test: Task 3, "turning MCP off closes the bridge".
3. **An agent passes the ID of an archived project or task.** The write refuses with the action set's reason, such as "Restore the task first". Test: Task 8, "refuses to start an entry on an archived task".
4. **An agent never ends its session.** It turns stalled at the deadline, and the indicator shows Failed. Tests: Task 10, "stalls past the deadline", and Task 12, "a stalled session shows Failed".
5. **An agent sends a date range of a year.** `list_time_entries` refuses spans over 62 days instead of returning thousands of entries. Test: Task 5, "refuses ranges over 62 days".

```ts
import { z } from "zod";

/**
 * Contracts between the local API's MCP endpoint and the renderer that runs
 * Ajour's data tools. See docs/superpowers/specs/2026-10-14-ajour-mcp-design.md.
 */

/** A local calendar date, such as 2026-10-14. */
export const isoDateSchema = z
  .string()
  .regex(/^\d{4}-\d{2}-\d{2}$/, "Use a date such as 2026-10-14.");

/** An agent client as Settings lists it. The token is never part of it. */
export const mcpClientSchema = z.object({
  id: z.string().min(1),
  name: z.string().min(1),
  createdAt: z.number(),
  lastUsedAt: z.number().optional(),
});
export type McpClient = z.infer<typeof mcpClientSchema>;

export const mcpSettingsSchema = z.object({
  enabled: z.boolean(),
  clients: z.array(mcpClientSchema),
});
export type McpSettings = z.infer<typeof mcpSettingsSchema>;

export const mcpSettingsUpdateSchema = z.object({ enabled: z.boolean() });

export const mcpClientCreateRequestSchema = z.object({
  name: z.string().trim().min(1).max(80),
});

/** The only place the token appears. Ajour keeps its hash. */
export const mcpClientCreateResponseSchema = z.object({
  client: mcpClientSchema,
  token: z.string().min(1),
});
export type McpClientCreateResponse = z.infer<
  typeof mcpClientCreateResponseSchema
>;

/** `ok` is false when the call had already timed out in the API. */
export const mcpBridgeResultAckSchema = z.object({ ok: z.boolean() });

/** The agent client behind a tool call, as the renderer and the panel see it. */
export const agentClientRefSchema = z.object({
  id: z.string(),
  name: z.string(),
});
export type AgentClientRef = z.infer<typeof agentClientRefSchema>;

/** A data tool call the API sends to the renderer. */
export const bridgeToolCallSchema = z.object({
  requestId: z.string().min(1),
  tool: z.string().min(1),
  input: z.unknown(),
  client: agentClientRefSchema,
});
export type BridgeToolCall = z.infer<typeof bridgeToolCallSchema>;

/** What the renderer posts back. A refusal carries a sentence for the agent. */
export const bridgeToolResultSchema = z.discriminatedUnion("ok", [
  z.object({
    requestId: z.string().min(1),
    ok: z.literal(true),
    output: z.unknown(),
    /** Set by write tools, for the activity list. Never a note. */
    activity: z
      .object({
        action: z.string(),
        objectId: z.string(),
        objectTitle: z.string(),
      })
      .optional(),
  }),
  z.object({
    requestId: z.string().min(1),
    ok: z.literal(false),
    error: z.string(),
  }),
]);
export type BridgeToolResult = z.infer<typeof bridgeToolResultSchema>;

/** Input schemas of the read tools, by MCP tool name. */
export const readToolInputSchemas = {
  get_running_timer: z.object({}),
  list_time_entries: z.object({ from: isoDateSchema, to: isoDateSchema }),
  list_projects: z.object({}),
  list_work_items: z.object({
    filter: z
      .enum(["sidebar", "active", "settled", "archived", "all"])
      .default("sidebar"),
    workflowStateId: z.string().optional(),
    projectId: z.string().optional(),
    text: z.string().optional(),
    limit: z.number().int().min(1).max(200).default(50),
  }),
  get_work_item: z.object({ workItemId: z.string().min(1) }),
  get_submit_lines: z.object({
    weekOf: isoDateSchema,
    groupBy: z.enum(["day-task", "day", "task"]).default("day-task"),
    onlyUnsubmitted: z.boolean().default(true),
  }),
} as const;
export type ReadToolName = keyof typeof readToolInputSchemas;
export type ReadToolInput<Name extends ReadToolName> = z.infer<
  (typeof readToolInputSchemas)[Name]
>;
```

```ts
/**
 * An agent client. Ajour keeps only the SHA-256 hash of its token. A revoked
 * client stays in the file so a rejected request can name it.
 */
export interface StoredMcpClient {
  id: string;
  name: string;
  tokenHash: string;
  createdAt: number;
  lastUsedAt?: number;
  revokedAt?: number;
}

interface StoredMcpState {
  enabled: boolean;
  clients: StoredMcpClient[];
}

/** Skips writing `lastUsedAt` more than once a minute per client. */
const MCP_LAST_USED_RESOLUTION_MS = 60_000;

function normalizeMcpState(raw: unknown): StoredMcpState {
  const value = (raw ?? {}) as Partial<StoredMcpState>;
  return {
    enabled: value.enabled === true,
    clients: (Array.isArray(value.clients) ? value.clients : []).filter(
      (client): client is StoredMcpClient =>
        typeof client?.id === "string" &&
        typeof client.name === "string" &&
        typeof client.tokenHash === "string" &&
        typeof client.createdAt === "number",
    ),
  };
}
```

```ts
  /** MCP settings for the Settings page. Revoked clients and token hashes stay out. */
  async getMcpSettings(): Promise<McpSettings> {
    const { mcp } = await this.readState();
    return {
      enabled: mcp.enabled,
      clients: mcp.clients
        .filter((client) => client.revokedAt === undefined)
        .map(({ id, name, createdAt, lastUsedAt }) => ({
          id,
          name,
          createdAt,
          ...(lastUsedAt === undefined ? {} : { lastUsedAt }),
        })),
    };
  }

  async setMcpEnabled(enabled: boolean): Promise<void> {
    await this.mutate((state) => ({
      nextState: { ...state, mcp: { ...state.mcp, enabled } },
      result: undefined,
    }));
  }

  async addMcpClient(client: StoredMcpClient): Promise<void> {
    await this.mutate((state) => ({
      nextState: {
        ...state,
        mcp: { ...state.mcp, clients: [...state.mcp.clients, client] },
      },
      result: undefined,
    }));
  }

  /** Revokes a client. False when no active client has the id. */
  async revokeMcpClient(clientId: string, at: number): Promise<boolean> {
    return this.mutate((state) => {
      const target = state.mcp.clients.find(
        (client) => client.id === clientId && client.revokedAt === undefined,
      );
      if (!target) return { nextState: state, result: false };
      return {
        nextState: {
          ...state,
          mcp: {
            ...state.mcp,
            clients: state.mcp.clients.map((client) =>
              client === target ? { ...client, revokedAt: at } : client,
            ),
          },
        },
        result: true,
      };
    });
  }

  /** Finds a client by token hash, revoked or not. */
  async findMcpClientByTokenHash(
    tokenHash: string,
  ): Promise<StoredMcpClient | undefined> {
    return (await this.readState()).mcp.clients.find(
      (client) => client.tokenHash === tokenHash,
    );
  }

  async touchMcpClient(clientId: string, at: number): Promise<void> {
    const client = (await this.readState()).mcp.clients.find(
      (candidate) => candidate.id === clientId,
    );
    if (
      !client ||
      (client.lastUsedAt !== undefined &&
        at - client.lastUsedAt < MCP_LAST_USED_RESOLUTION_MS)
    ) {
      return;
    }
    await this.mutate((state) => ({
      nextState: {
        ...state,
        mcp: {
          ...state.mcp,
          clients: state.mcp.clients.map((candidate) =>
            candidate.id === clientId
              ? { ...candidate, lastUsedAt: at }
              : candidate,
          ),
        },
      },
      result: undefined,
    }));
  }
```

- [ ] **Step 4: Write `mcp-clients.ts`**

```ts
import { createHash, randomBytes, randomUUID } from "node:crypto";
import type { McpClientCreateResponse } from "../../../packages/shared/agent-tools.ts";
import type { AppApiStorage, StoredMcpClient } from "./storage.ts";

/**
 * Agent client tokens. A token is 32 random bytes, shown once when the client
 * is created. Ajour stores its SHA-256 hash and compares hashes.
 */

export type McpAuthentication =
  | { kind: "ok"; client: StoredMcpClient }
  | { kind: "missing" }
  | { kind: "unknown" }
  | { kind: "revoked"; client: StoredMcpClient };

export function hashMcpToken(token: string) {
  return createHash("sha256").update(token).digest("hex");
}

export async function createMcpClient(
  storage: AppApiStorage,
  name: string,
  now = Date.now(),
): Promise<McpClientCreateResponse> {
  const token = `ajour_${randomBytes(32).toString("base64url")}`;
  const client: StoredMcpClient = {
    id: randomUUID(),
    name,
    tokenHash: hashMcpToken(token),
    createdAt: now,
  };
  await storage.addMcpClient(client);
  return { client: { id: client.id, name, createdAt: now }, token };
}

/** Reads `Authorization: Bearer <token>` and finds the client it belongs to. */
export async function authenticateMcpRequest(
  storage: AppApiStorage,
  authorization: string | undefined,
  now = Date.now(),
): Promise<McpAuthentication> {
  const token = authorization?.match(/^Bearer\s+(\S+)$/i)?.[1];
  if (!token) return { kind: "missing" };

  const client = await storage.findMcpClientByTokenHash(hashMcpToken(token));
  if (!client) return { kind: "unknown" };
  if (client.revokedAt !== undefined) return { kind: "revoked", client };

  await storage.touchMcpClient(client.id, now);
  return { kind: "ok", client };
}
```

```ts
import { randomUUID } from "node:crypto";
import type { ServerResponse } from "node:http";
import type {
  AgentClientRef,
  BridgeToolResult,
} from "../../../packages/shared/agent-tools.ts";

/**
 * The event stream from the local API to the Ajour window. The renderer owns
 * all data, so every data tool runs there: the API sends a `tool-call` event,
 * the renderer posts the result to /api/mcp/bridge/results. One stream is
 * active at a time. A new one, such as after a reload, replaces the old one.
 */

export const BRIDGE_UNAVAILABLE_MESSAGE =
  "Open the Ajour window to use this tool.";
export const BRIDGE_TIMEOUT_MESSAGE = "Ajour did not answer in time.";

const DEFAULT_TIMEOUT_MS = 10_000;
const KEEP_ALIVE_MS = 25_000;

export class BridgeCallError extends Error {
  constructor(
    message: string,
    readonly reason: "unavailable" | "timeout",
  ) {
    super(message);
    this.name = "BridgeCallError";
  }
}

interface PendingCall {
  resolve: (result: BridgeToolResult) => void;
  reject: (error: Error) => void;
  timer: NodeJS.Timeout;
}

export class McpBridge {
  private stream?: ServerResponse;
  private keepAlive?: NodeJS.Timeout;
  private readonly pending = new Map<string, PendingCall>();
  private readonly timeoutMs: number;
  private readonly onAttach?: () => void;

  constructor(options: { timeoutMs?: number; onAttach?: () => void } = {}) {
    this.timeoutMs = options.timeoutMs ?? DEFAULT_TIMEOUT_MS;
    this.onAttach = options.onAttach;
  }

  get connected() {
    return this.stream !== undefined && !this.stream.writableEnded;
  }

  /** Makes `response` the renderer's stream. Ends the previous one. */
  attach(response: ServerResponse) {
    this.detach();
    response.writeHead(200, {
      "Content-Type": "text/event-stream; charset=utf-8",
      "Cache-Control": "no-cache, no-transform",
      Connection: "keep-alive",
    });
    response.write("retry: 2000\n\n");
    this.stream = response;
    this.keepAlive = setInterval(() => {
      response.write(": keep-alive\n\n");
    }, KEEP_ALIVE_MS);
    this.keepAlive.unref();
    response.on("close", () => {
      if (this.stream === response) this.clearStream();
    });
    this.onAttach?.();
  }

  /** Runs a data tool in the renderer. Rejects with a `BridgeCallError`. */
  call(
    tool: string,
    input: unknown,
    client: AgentClientRef,
  ): Promise<BridgeToolResult> {
    if (!this.connected) {
      return Promise.reject(
        new BridgeCallError(BRIDGE_UNAVAILABLE_MESSAGE, "unavailable"),
      );
    }

    const requestId = randomUUID();
    return new Promise((resolve, reject) => {
      const timer = setTimeout(() => {
        this.pending.delete(requestId);
        reject(new BridgeCallError(BRIDGE_TIMEOUT_MESSAGE, "timeout"));
      }, this.timeoutMs);
      this.pending.set(requestId, { resolve, reject, timer });
      this.send("tool-call", { requestId, tool, input, client });
    });
  }

  /** Settles a pending call. False when it already timed out. */
  resolve(result: BridgeToolResult) {
    const pending = this.pending.get(result.requestId);
    if (!pending) return false;
    clearTimeout(pending.timer);
    this.pending.delete(result.requestId);
    pending.resolve(result);
    return true;
  }

  /** Sends a named event, such as the agents snapshot, when a renderer listens. */
  publish(event: string, data: unknown) {
    if (this.connected) this.send(event, data);
  }

  /** Ends the stream and fails pending calls, when MCP turns off or the API stops. */
  close() {
    this.detach();
    for (const [requestId, pending] of this.pending) {
      clearTimeout(pending.timer);
      this.pending.delete(requestId);
      pending.reject(
        new BridgeCallError(BRIDGE_UNAVAILABLE_MESSAGE, "unavailable"),
      );
    }
  }

  private send(event: string, data: unknown) {
    this.stream?.write(`event: ${event}\ndata: ${JSON.stringify(data)}\n\n`);
  }

  private detach() {
    const stream = this.stream;
    this.clearStream();
    stream?.end();
  }

  private clearStream() {
    if (this.keepAlive) clearInterval(this.keepAlive);
    this.keepAlive = undefined;
    this.stream = undefined;
  }
}
```

```ts
import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
import { StreamableHTTPServerTransport } from "@modelcontextprotocol/sdk/server/streamableHttp.js";
import {
  readToolInputSchemas,
  type AgentClientRef,
  type ReadToolName,
} from "../../../packages/shared/agent-tools.ts";
import { BridgeCallError, type McpBridge } from "./mcp-bridge.ts";
import { authenticateMcpRequest } from "./mcp-clients.ts";
import type { AppApiStorage } from "./storage.ts";

/**
 * Ajour's MCP endpoint, /mcp/ajour, over Streamable HTTP. Each request gets
 * its own server and transport (stateless mode), bound to the client its
 * token names. Data tools run in the renderer through the bridge.
 */

export interface McpRequestContext {
  storage: AppApiStorage;
  bridge: McpBridge;
  logEvent: (event: Record<string, unknown>) => void;
  readBody: (request: IncomingMessage) => Promise<unknown>;
}

export interface ToolResult {
  [key: string]: unknown;
  content: { type: "text"; text: string }[];
  isError?: boolean;
}

/** What every agent reads first. Spec B's plugins add their own. */
const AJOUR_INSTRUCTIONS = [
  "Ajour is the user's local time tracker: timers, time entries, projects and tasks, and a backlog.",
  "Use the ids that the list tools return. Durations are in minutes unless a field says hours.",
  "A write refused by Ajour returns an error with the reason. Do not retry it unchanged.",
].join("\n");

/** Tool descriptions, by tool name. Later tasks add write and session tools. */
export const TOOL_DESCRIPTIONS: Record<ReadToolName, string> = {
  get_running_timer:
    "The running entry, with its project, task, note and counted minutes. Null when nothing runs.",
  list_time_entries:
    "Time entries between two dates (inclusive, at most 62 days), each with its state: saved or submitted. The running entry is returned separately.",
  list_projects: "Active projects and their active tasks, with their ids.",
  list_work_items:
    "Backlog items. The default `sidebar` filter returns the user's current work list in their order. Filter by workflow state, project or text.",
  get_work_item: "One backlog item with its note, source link and subitems.",
  get_submit_lines:
    "The week's timesheet lines as the Submit page groups them, with hours, merged comments and warnings. `weekOf` is any date in the week.",
};

export function textResult(value: unknown): ToolResult {
  return { content: [{ type: "text", text: JSON.stringify(value, null, 2) }] };
}

export function errorResult(message: string): ToolResult {
  return { content: [{ type: "text", text: message }], isError: true };
}

/** Sends a data tool to the renderer and logs one `mcp.request` event. */
export async function forwardToRenderer(
  tool: string,
  input: unknown,
  client: AgentClientRef,
  context: McpRequestContext,
): Promise<ToolResult> {
  const startedAt = Date.now();
  const event: Record<string, unknown> = {
    event: "mcp.request",
    client_id: client.id,
    tool,
  };
  try {
    const result = await context.bridge.call(tool, input, client);
    event.bridge_ms = Date.now() - startedAt;
    if (!result.ok) {
      event.outcome = "refused";
      return errorResult(result.error);
    }
    event.outcome = "ok";
    return textResult(result.output);
  } catch (error) {
    if (error instanceof BridgeCallError) {
      event.outcome = error.reason;
      return errorResult(error.message);
    }
    event.outcome = "error";
    throw error;
  } finally {
    event.duration_ms = Date.now() - startedAt;
    context.logEvent(event);
  }
}

/** Registers every tool for one request, bound to its client. */
export function registerTools(
  server: McpServer,
  client: AgentClientRef,
  context: McpRequestContext,
) {
  for (const name of Object.keys(readToolInputSchemas) as ReadToolName[]) {
    server.registerTool(
      name,
      {
        description: TOOL_DESCRIPTIONS[name],
        inputSchema: readToolInputSchemas[name].shape,
      },
      async (input) => forwardToRenderer(name, input, client, context),
    );
  }
}

function writeError(response: ServerResponse, status: number, message: string) {
  const headers: Record<string, string> = {
    "Content-Type": "application/json; charset=utf-8",
  };
  if (status === 401) headers["WWW-Authenticate"] = "Bearer";
  response.writeHead(status, headers);
  response.end(JSON.stringify({ error: message }));
}

export async function handleMcpRequest(
  request: IncomingMessage,
  response: ServerResponse,
  pathname: string,
  context: McpRequestContext,
) {
  // Agents are not browsers. An Origin header means a web page is calling.
  if (request.headers.origin) {
    context.logEvent({ event: "mcp.request", outcome: "browser_refused" });
    writeError(response, 403, "MCP does not accept browser requests.");
    return;
  }
  if (
    pathname !== "/mcp/ajour" ||
    !(await context.storage.getMcpSettings()).enabled
  ) {
    writeError(response, 404, "Not found.");
    return;
  }

  const authentication = await authenticateMcpRequest(
    context.storage,
    request.headers.authorization,
  );
  if (authentication.kind !== "ok") {
    context.logEvent({
      event: "mcp.request",
      outcome: "unauthorized",
      reason: authentication.kind,
      client_id:
        authentication.kind === "revoked"
          ? authentication.client.id
          : undefined,
    });
    writeError(response, 401, "Unknown or revoked token.");
    return;
  }

  const client = {
    id: authentication.client.id,
    name: authentication.client.name,
  };
  const server = new McpServer(
    { name: "ajour", version: "1.0.0" },
    { instructions: AJOUR_INSTRUCTIONS },
  );
  registerTools(server, client, context);
  const transport = new StreamableHTTPServerTransport({
    sessionIdGenerator: undefined,
    enableJsonResponse: true,
  });
  response.on("close", () => {
    void transport.close();
    void server.close();
  });
  await server.connect(transport);
  const body =
    request.method === "POST" ? await context.readBody(request) : undefined;
  await transport.handleRequest(request, response, body);
}
```

```js
/**
 * Finds a package's own package.json from `searchPaths`, walking up the
 * node_modules folders like Node does. require.resolve can't be used: packages
 * with an `exports` wildcard map package.json to a file in their dist folder.
 */
function findPackageJson(packageName, searchPaths) {
  for (const searchPath of searchPaths) {
    let directory = realpathSync(searchPath);
    for (;;) {
      const candidate = path.join(
        directory,
        "node_modules",
        packageName,
        "package.json",
      );
      if (existsSync(candidate)) return realpathSync(candidate);
      const parent = path.dirname(directory);
      if (parent === directory) break;
      directory = parent;
    }
  }
  throw new Error(`Missing internal API runtime package: ${packageName}`);
}
```

```ts
  now: number,

    timerId: timer._id,

        MINUTE,

function dayNumber(isoDate: string) {
  const [year, month, day] = isoDate.split("-").map(Number);
  return Date.UTC(year!, month! - 1, day!) / DAY;
}

export function listTimeEntriesForAgent(
  state: LocalAppState,
  { from, to }: ReadToolInput<"list_time_entries">,
  now: number,
) {
  const span = dayNumber(to) - dayNumber(from);
  if (span < 0) {
    throw new AgentToolRefusal("`from` must be on or before `to`.");
  }
  if (span > MAX_RANGE_DAYS) {
    throw new AgentToolRefusal(
      `Ask for at most ${MAX_RANGE_DAYS} days at a time.`,
    );
  }

  const running = readRunningTimer(state, now);
  return {
    entries: state.timesheetEntries
      .filter((entry) => entry.localDate >= from && entry.localDate <= to)
      .sort(
        (left, right) =>
          left.localDate.localeCompare(right.localDate) ||
          left.committedAt - right.committedAt,
      )
      .map((entry) => toAgentEntry(state, entry)),
    running:
      running && running.date >= from && running.date <= to ? running : null,
  };
}

    (candidate) => candidate._id === item.workflowStateId,
  );
  return {

    title: item.title,
    status: item.status,

          workflowState: workflowState.name,
          workflowStateId: workflowState._id,
        }
      : {}),
    priority: item.priority ?? null,
    ...(item.remainingEstimateHours !== undefined
      ? { remainingEstimateHours: item.remainingEstimateHours }
      : {}),
    ...(item.parentWorkItemId
      ? { parentWorkItemId: item.parentWorkItemId }
      : {}),
    source: item.source,
    ...(item.sourceProjectName
      ? { sourceProjectName: item.sourceProjectName }
      : {}),
    ...(isBacklogItemSnoozed(item, now) && item.snoozedUntil !== undefined
      ? { snoozedUntil: new Date(item.snoozedUntil).toISOString() }
      : {}),
    ...describeProjectTask(state, item.projectId, item.taskId),
  };
}

export function listWorkItemsForAgent(
  state: LocalAppState,
  input: ReadToolInput<"list_work_items">,
  now: number,
): AgentWorkItem[] {
  const base =
    input.filter === "sidebar"
      ? selectSidebarBacklogItems(state, now)
      : input.filter === "all"
        ? state.workItems
        : state.workItems.filter((item) => item.status === input.filter);
  const text = input.text?.trim().toLowerCase();

  return base
    .filter(
      (item) =>
        (input.workflowStateId === undefined ||
          item.workflowStateId === input.workflowStateId) &&
        (input.projectId === undefined || item.projectId === input.projectId) &&
        (!text || item.title.toLowerCase().includes(text)),
    )
    .slice(0, input.limit)
    .map((item) => toAgentWorkItem(state, item, now));
}
```

```ts
import { ZodError } from "zod";
import {
  readToolInputSchemas,
  type BridgeToolCall,
  type BridgeToolResult,
  type ReadToolName,
} from "@ajour/shared/agent-tools";
import {
  getSubmitLinesForAgent,
  getWorkItemForAgent,
  listProjectsForAgent,
  listTimeEntriesForAgent,
  listWorkItemsForAgent,
  readRunningTimer,
} from "@/domain/agents/agent-read-model";
import { AgentToolRefusal } from "@/domain/agents/agent-tool-refusal";
import { localStore } from "@/lib/local-store";
import { getIsoWeekDates } from "@/lib/utils";

/**
 * Runs the data tools an agent calls through the local API's bridge. Inputs
 * are validated again here: the renderer does not trust the API's parsing.
 * A refusal returns a sentence the agent can act on. Anything else throws,
 * and the bridge reports it as a failure.
 */

function isReadTool(tool: string): tool is ReadToolName {
  return Object.hasOwn(readToolInputSchemas, tool);
}

function formatZodError(error: ZodError) {
  return error.issues
    .map((issue) =>
      issue.path.length > 0
        ? `${issue.path.join(".")}: ${issue.message}`
        : issue.message,
    )
    .join(" ");
}

function runReadTool(tool: ReadToolName, rawInput: unknown): unknown {
  const state = localStore.snapshot();
  const now = Date.now();
  switch (tool) {
    case "get_running_timer":
      return readRunningTimer(state, now);
    case "list_time_entries":
      return listTimeEntriesForAgent(
        state,
        readToolInputSchemas.list_time_entries.parse(rawInput),
        now,
      );
    case "list_projects":
      return listProjectsForAgent(state);
    case "list_work_items":
      return listWorkItemsForAgent(
        state,
        readToolInputSchemas.list_work_items.parse(rawInput),
        now,
      );
    case "get_work_item":
      return getWorkItemForAgent(
        state,
        readToolInputSchemas.get_work_item.parse(rawInput).workItemId,
        now,
      );
    case "get_submit_lines": {
      const input = readToolInputSchemas.get_submit_lines.parse(rawInput);
      return getSubmitLinesForAgent(state, {
        weekDates: getIsoWeekDates(input.weekOf),
        groupBy: input.groupBy,
        onlyUnsubmitted: input.onlyUnsubmitted,
      });
    }
  }
}

export function runAgentToolCall(call: BridgeToolCall): BridgeToolResult {
  const refuse = (error: string): BridgeToolResult => ({
    requestId: call.requestId,
    ok: false,
    error,
  });

  try {
    if (isReadTool(call.tool)) {
      return {
        requestId: call.requestId,
        ok: true,
        output: runReadTool(call.tool, call.input),
      };
    }
    return refuse(`Ajour has no tool named ${call.tool}.`);
  } catch (error) {
    if (error instanceof AgentToolRefusal) return refuse(error.message);
    if (error instanceof ZodError) return refuse(formatZodError(error));
    throw error;
  }
}
```

```ts
/**
 * MCP settings from the local API, shared by Settings > MCP and the agent
 * bridge. `unavailable` means Ajour runs as a plain web app without the API.
 */
export type McpSettingsState =
  | { kind: "loading" }
  | { kind: "unavailable" }
  | { kind: "error"; message: string }
  | { kind: "ready"; settings: McpSettings };

let current: McpSettingsState = { kind: "loading" };
let loaded = false;
const listeners = new Set<() => void>();

function publish(next: McpSettingsState) {
  current = next;
  listeners.forEach((listener) => listener());
}

export function setMcpSettings(settings: McpSettings) {
  publish({ kind: "ready", settings });
}

export async function refreshMcpSettings() {
  try {
    setMcpSettings(await getMcpSettings());
  } catch (error) {
    publish(
      isConnectorApiMissing(error)
        ? { kind: "unavailable" }
        : {
            kind: "error",
            message: error instanceof Error ? error.message : "Unknown error",
          },
    );
  }
}

function subscribe(listener: () => void) {
  listeners.add(listener);
  if (!loaded) {
    loaded = true;
    void refreshMcpSettings();
  }
  return () => listeners.delete(listener);
}

export function useMcpSettings(): McpSettingsState {
  return useSyncExternalStore(subscribe, () => current);
}
```

```ts
import {
  bridgeToolCallSchema,
  type BridgeToolCall,
  type BridgeToolResult,
} from "@ajour/shared/agent-tools";
import { getAppApiBaseUrl, postMcpBridgeResult } from "@/lib/app-api";

/**
 * The Ajour window's end of the MCP bridge. The local API sends data tool
 * calls on an event stream; this runs them one at a time, in arrival order,
 * and posts each result back. EventSource reconnects on its own after a
 * network error. A refused connection (MCP off) closes it for good.
 */

export type McpBridgeStatus = "connecting" | "connected" | "disconnected";

export interface McpBridgeHandlers {
  runToolCall(
    call: BridgeToolCall,
  ): BridgeToolResult | Promise<BridgeToolResult>;
  onStatus(status: McpBridgeStatus): void;
}

async function runSafely(
  handlers: McpBridgeHandlers,
  call: BridgeToolCall,
): Promise<BridgeToolResult> {
  try {
    return await handlers.runToolCall(call);
  } catch (error) {
    return {
      requestId: call.requestId,
      ok: false,
      error:
        error instanceof Error ? error.message : "The tool failed in Ajour.",
    };
  }
}

/** Opens the bridge. Returns a function that closes it. */
export function connectMcpBridge(handlers: McpBridgeHandlers): () => void {
  const source = new EventSource(`${getAppApiBaseUrl()}/api/mcp/bridge`);
  let queue: Promise<void> = Promise.resolve();

  handlers.onStatus("connecting");
  source.onopen = () => handlers.onStatus("connected");
  source.onerror = () =>
    handlers.onStatus(
      source.readyState === EventSource.CLOSED ? "disconnected" : "connecting",
    );
  source.addEventListener("tool-call", (message) => {
    const parsed = bridgeToolCallSchema.safeParse(
      JSON.parse((message as MessageEvent<string>).data),
    );
    if (!parsed.success) return;
    queue = queue.then(async () => {
      const result = await runSafely(handlers, parsed.data);
      // A lost post leaves the API to time the call out, which the agent sees.
      await postMcpBridgeResult(result).catch(() => undefined);
    });
  });

  return () => {
    source.close();
    handlers.onStatus("disconnected");
  };
}
```

```ts
  /**
   * Runs store commands as one undoable action, for callers such as agent
   * tools whose commands keep no undo of their own. The undo covers every
   * record the commands changed. Replaces the last undo, like any action.
   */
  runWithUndo<T>(run: () => T): { result: T; undoToken: string | null } {
    const before = readState();
    const result = run();
    const after = readState();
    if (after === before) return { result, undoToken: null };

    const undo = captureUndo(before, after);
    if (!undo) return { result, undoToken: null };
    const token = createId("undo");
    lastUndo = { token, undo };
    return { result, undoToken: token };
  },
```

```ts
export function assertAllowed<Id extends string>(
  actions: ObjectAction<Id>[],
  id: Id,
) {
  const action = actions.find((candidate) => candidate.id === id);
  if (!action) {
    throw new AgentToolRefusal(`Ajour does not offer ${id} for this object.`);
  }
  if (action.disabledReason) throw new AgentToolRefusal(action.disabledReason);

/** Finds an active project and task an entry can go to. */
export function requireProjectTask(
  state: LocalAppState,
  projectId: string,
  taskId?: string,
) {
  const project = state.projects.find(
    (candidate) => candidate._id === projectId,
  );
  if (!project) {
    throw new AgentToolRefusal(
      `No project has the id ${projectId}. Call list_projects.`,
    );

  if (taskId === undefined) {

    return {
      project,
      task: undefined,
      title: getLocalProjectDisplayName(project),

export function runEntryWriteTool(
  tool: EntryWriteTool,
  rawInput: unknown,

  const state = localStore.snapshot();
  const now = Date.now();

  switch (tool) {
    case "start_timer": {

      let draft: Parameters<typeof localStore.startTimer>[0];
      let title: string;
      if (input.workItemId) {
        const item = state.workItems.find(
          (candidate) => candidate._id === input.workItemId,
        );
        if (!item) {
          throw new AgentToolRefusal(
            `No backlog item has the id ${input.workItemId}. Call list_work_items.`,
          );

          getBacklogItemActions(item, backlogActionOptions(state, item, now)),
          "start-entry",

          ? input.taskId
          : (input.taskId ?? item.taskId);
        if (projectId) requireProjectTask(state, projectId, taskId);
        draft = { workItemId: item._id, projectId, taskId, note: input.note };
        title = item.title;
      } else if (input.projectId) {
        const target = requireProjectTask(state, input.projectId, input.taskId);
        draft = {
          projectId: input.projectId,
          taskId: input.taskId,
          note: input.note,
        };
        title = target.title;
      } else {
        throw new AgentToolRefusal(
          "Pass a workItemId, or a projectId with an optional taskId.",
        );
      }
      const { undoToken } = localStore.runWithUndo(() =>
        localStore.startTimer(draft),
      );
      const running = readRunningTimer(localStore.snapshot(), Date.now());
      return {
        output: running,
        undoToken,
        action: "Started an entry",
        objectId: running?.timerId ?? "",
        objectTitle: title,
        undoSubject: "entry",
      };
    }

    case "stop_timer": {
      writeToolInputSchemas.stop_timer.parse(rawInput);
      const timer = state.timers[0];
      if (!timer) throw new AgentToolRefusal("No entry is running.");
      const running = readRunningTimer(state, now)!;
      const { undoToken } = localStore.runWithUndo(() =>
        localStore.saveTimer(timer._id),
      );
      return {
        output: { stopped: true, countedMinutes: running.countedMinutes },
        undoToken,
        action: "Stopped the entry",
        objectId: timer._id,
        objectTitle:
          [running.projectName, running.taskName].filter(Boolean).join(" · ") ||
          "Running entry",
        undoSubject: "entry",
      };
    }

    case "edit_running_entry": {
      const input = writeToolInputSchemas.edit_running_entry.parse(rawInput);
      const timer = state.timers[0];
      if (!timer) throw new AgentToolRefusal("No entry is running.");
      const projectId = input.projectId ?? timer.projectId;
      const taskId = input.projectId
        ? input.taskId
        : (input.taskId ?? timer.taskId);
      if (projectId) requireProjectTask(state, projectId, taskId);
      const { undoToken } = localStore.runWithUndo(() =>
        localStore.editRunningEntry(timer._id, {
          projectId,
          taskId,
          note: input.note ?? timer.note,
          ...(input.countedMinutes !== undefined
            ? { countedDurationMs: input.countedMinutes * MINUTE }
            : {}),
        }),
      );
      const running = readRunningTimer(localStore.snapshot(), Date.now());
      return {
        output: running,
        undoToken,
        action: "Edited the running entry",
        objectId: timer._id,
        objectTitle:
          [running?.projectName, running?.taskName]
            .filter(Boolean)
            .join(" · ") || "Running entry",
        undoSubject: "entry",
      };
    }

    case "create_entry": {
      const input = writeToolInputSchemas.create_entry.parse(rawInput);
      const target = requireProjectTask(state, input.projectId, input.taskId);
      const { undoToken } = localStore.runWithUndo(() =>
        localStore.saveManualTimeEntry({
          localDate: input.date,
          projectId: input.projectId,
          taskId: input.taskId,
          workItemId: input.workItemId,
          note: input.note,
          durationMs: input.minutes * MINUTE,
        }),
      );
      const after = localStore.snapshot();
      const entry = addedEntry(state, after);
      if (!entry) throw new AgentToolRefusal("Ajour did not add the entry.");
      return {
        output: toAgentEntry(after, entry),
        undoToken,
        action: "Added an entry",
        objectId: entry._id,
        objectTitle: target.title,
        undoSubject: "entry",
      };
    }

    case "edit_entry": {
      const input = writeToolInputSchemas.edit_entry.parse(rawInput);
      const entry = requireEntry(state, input.entryId);
      if (isEntryRunning(state, entry)) {
        throw new AgentToolRefusal(
          "Use edit_running_entry for the running entry.",
        );
      }
      assertAllowed(entryActions(state, entry), "edit");
      const projectId = input.projectId ?? entry.projectId;
      const taskId = input.projectId
        ? input.taskId
        : (input.taskId ?? entry.taskId);
      if (projectId) requireProjectTask(state, projectId, taskId);
      const { undoToken } = localStore.runWithUndo(() =>
        localStore.updateTimesheetEntry(entry._id, {
          projectId,
          taskId,
          note: input.note ?? entry.note,
          durationMs:
            input.minutes !== undefined
              ? input.minutes * MINUTE
              : entry.durationMs,
        }),
      );
      const after = localStore.snapshot();
      const updated = requireEntry(after, entry._id);
      return {
        output: toAgentEntry(after, updated),
        undoToken,
        action: "Edited an entry",
        objectId: entry._id,
        objectTitle: entryTitle(after, updated),
        undoSubject: "entry",
      };
    }

    case "move_entry":
    case "duplicate_entry": {
      const input =
        tool === "move_entry"
          ? writeToolInputSchemas.move_entry.parse(rawInput)
          : writeToolInputSchemas.duplicate_entry.parse(rawInput);
      const entry = requireEntry(state, input.entryId);
      assertAllowed(
        entryActions(state, entry),
        tool === "move_entry"
          ? "move-to"
          : input.date
            ? "duplicate-to"
            : "duplicate",
      );
      const values = {
        localDate: input.date ?? entry.localDate,
        projectId: entry.projectId,
        taskId: entry.taskId,
        note: entry.note,
        durationMs: entry.durationMs,
      };
      const { undoToken } = localStore.runWithUndo(() =>
        tool === "move_entry"
          ? localStore.moveTimesheetEntry(entry._id, values)
          : localStore.duplicateTimesheetEntry(entry._id, values),
      );
      const after = localStore.snapshot();
      const result =
        tool === "move_entry"
          ? after.timesheetEntries.find(
              (candidate) => candidate._id === entry._id,
            )
          : addedEntry(state, after);
      return {
        output: result ? toAgentEntry(after, result) : null,
        undoToken,
        action:
          tool === "move_entry" ? "Moved an entry" : "Duplicated an entry",
        objectId: result?._id ?? entry._id,
        objectTitle: entryTitle(state, entry),
        undoSubject: "entry",
      };
    }

    case "mark_entries_submitted": {
      const input =
        writeToolInputSchemas.mark_entries_submitted.parse(rawInput);
      for (const entryId of input.entryIds) {
        const entry = requireEntry(state, entryId);
        if (isEntryRunning(state, entry)) {
          throw new AgentToolRefusal("Stop the running entry first");
        }
      }
      const { undoToken } = localStore.runWithUndo(() =>
        localStore.markTimesheetEntriesSubmitted(input.entryIds),
      );
      const count = input.entryIds.length;
      return {
        output: { marked: count },
        undoToken,
        action: `Marked ${count} ${count === 1 ? "entry" : "entries"} as submitted`,
        objectId: input.entryIds[0]!,
        objectTitle: `${count} ${count === 1 ? "entry" : "entries"}`,
        undoSubject: "entry",
      };
    }
  }
}
```

`requireProjectTask` with a task checks the task's `start-entry` action. That reason covers both an archived task and an archived project, which is what creating or moving time onto it needs.

```ts
import {
  writeToolInputSchemas,
  type WriteToolName,
} from "@ajour/shared/agent-tools";
import { getBacklogItemActions } from "@/domain/actions/object-actions";
import {
  findWorkItemOrRefuse,
  toAgentWorkItem,
} from "@/domain/agents/agent-read-model";
import { AgentToolRefusal } from "@/domain/agents/agent-tool-refusal";
import { getOpenSubitems } from "@/domain/backlog/backlog-item-lifecycle";
import type { LocalAppState, LocalWorkItem } from "@/domain/local-state";
import { canWriteToSource } from "@/features/backlog/backlog-source-writes";
import {
  assertAllowed,
  backlogActionOptions,
  requireProjectTask,
  type AgentWriteOutcome,
} from "@/features/agents/agent-write-tools";
import { localStore } from "@/lib/local-store";

/**
 * Backlog item tools. Like the UI, they check the item's action set. In v1
 * they leave synced items that write their state to the source to the user,
 * because those moves can open a source state dialog.
 */

export const WORK_ITEM_WRITE_TOOLS = [
  "create_work_item",
  "edit_work_item",
  "move_work_item",
  "settle_work_item",
  "unsettle_work_item",
  "snooze_work_item",
  "unsnooze_work_item",
  "archive_work_item",
  "restore_work_item",
] as const satisfies readonly WriteToolName[];
export type WorkItemWriteTool = (typeof WORK_ITEM_WRITE_TOOLS)[number];

function refuseSourceWrites(item: LocalWorkItem) {
  if (canWriteToSource(item)) {
    throw new AgentToolRefusal(
      "This item writes its state to its source, which can need a choice in Ajour. Ask the user to do it.",
    );
  }
}

/**
 * Whether a close or settle takes the item's open subitems along: the
 * agent's answer, else the user's setting. Refuses when the setting says Ask.
 */
function resolveIncludeSubitems(
  state: LocalAppState,
  item: LocalWorkItem,
  verb: "settle" | "close",
  requested: boolean | undefined,
) {
  const open = getOpenSubitems(state, item._id, verb);
  if (open.length === 0) return false;
  if (requested !== undefined) return requested;
  switch (state.userPreferences.closeParentSubitems) {
    case "include":
      return true;
    case "leave":
      return false;
    default:
      throw new AgentToolRefusal(
        `This item has ${open.length} open ${open.length === 1 ? "subitem" : "subitems"}. Call again with includeSubitems true or false.`,
      );
  }
}

function outcome(
  workItemId: string,
  undoToken: string | null,
  action: string,
): AgentWriteOutcome {
  const after = localStore.snapshot();
  const item = findWorkItemOrRefuse(after, workItemId);
  return {
    output: toAgentWorkItem(after, item, Date.now()),
    undoToken,
    action,
    objectId: item._id,
    objectTitle: item.title,
    undoSubject: "backlog item",
  };
}

export function runWorkItemWriteTool(
  tool: WorkItemWriteTool,
  rawInput: unknown,
): AgentWriteOutcome {
  const state = localStore.snapshot();
  const now = Date.now();
  const actionsFor = (item: LocalWorkItem) =>
    getBacklogItemActions(item, backlogActionOptions(state, item, now));

  switch (tool) {
    case "create_work_item": {
      const input = writeToolInputSchemas.create_work_item.parse(rawInput);
      if (input.parentWorkItemId) {
        assertAllowed(
          actionsFor(findWorkItemOrRefuse(state, input.parentWorkItemId)),
          "add-subitem",
        );
      }
      if (
        input.workflowStateId &&
        !state.workflowStates.some((item) => item._id === input.workflowStateId)
      ) {
        throw new AgentToolRefusal(
          `No workflow state has the id ${input.workflowStateId}.`,
        );
      }
      if (input.projectId) {
        requireProjectTask(state, input.projectId, input.taskId);
      }
      const { result: workItemId, undoToken } = localStore.runWithUndo(() =>
        localStore.addWorkItem({
          title: input.title,
          note: input.note,
          projectId: input.projectId,
          taskId: input.taskId,
          priority: input.priority ?? undefined,
          workflowStateId: input.workflowStateId,
          parentWorkItemId: input.parentWorkItemId,
          remainingEstimateHours: input.remainingEstimateHours,
          originalEstimateHours: input.remainingEstimateHours,
        }),
      );
      return outcome(workItemId, undoToken, "Added a backlog item");
    }

    case "edit_work_item": {
      const input = writeToolInputSchemas.edit_work_item.parse(rawInput);
      const item = findWorkItemOrRefuse(state, input.workItemId);
      assertAllowed(actionsFor(item), "edit");
      if (input.projectId) {
        requireProjectTask(state, input.projectId, input.taskId ?? undefined);
      }
      const patch = {
        ...(input.title !== undefined ? { title: input.title } : {}),
        ...(input.note !== undefined ? { note: input.note } : {}),
        ...(input.priority !== undefined
          ? { priority: input.priority ?? undefined }
          : {}),
        ...(input.remainingEstimateHours !== undefined
          ? {
              remainingEstimateHours: input.remainingEstimateHours ?? undefined,
            }
          : {}),
        ...(input.projectId !== undefined
          ? { projectId: input.projectId ?? undefined }
          : {}),
        ...(input.taskId !== undefined
          ? { taskId: input.taskId ?? undefined }
          : {}),
      };
      const undoToken = localStore.updateWorkItemWithUndo(item._id, patch);
      return outcome(item._id, undoToken, "Edited a backlog item");
    }

    case "move_work_item": {
      const input = writeToolInputSchemas.move_work_item.parse(rawInput);
      const item = findWorkItemOrRefuse(state, input.workItemId);
      const destination = state.workflowStates.find(
        (candidate) => candidate._id === input.workflowStateId,
      );
      if (!destination) {
        throw new AgentToolRefusal(
          `No workflow state has the id ${input.workflowStateId}.`,
        );
      }
      refuseSourceWrites(item);
      const closes = destination.done === true && item.status !== "archived";
      const includeSubitems = closes
        ? resolveIncludeSubitems(state, item, "close", input.includeSubitems)
        : false;
      const undoToken = localStore.moveWorkItemToState(
        item._id,
        destination._id,
        {
          includeSubitems,
        },
      );
      const reopens = !destination.done && item.status === "archived";
      return outcome(
        item._id,
        undoToken,
        closes
          ? `Closed in ${destination.name}`
          : reopens
            ? `Reopened in ${destination.name}`
            : `Moved to ${destination.name}`,
      );
    }

    case "settle_work_item": {
      const input = writeToolInputSchemas.settle_work_item.parse(rawInput);
      const item = findWorkItemOrRefuse(state, input.workItemId);
      assertAllowed(actionsFor(item), "settle");
      refuseSourceWrites(item);
      const includeSubitems = resolveIncludeSubitems(
        state,
        item,
        "settle",
        input.includeSubitems,
      );
      const undoToken = localStore.settleWorkItem(item._id, undefined, {
        includeSubitems,
      });
      return outcome(item._id, undoToken, "Settled a backlog item");
    }

    case "snooze_work_item": {
      const input = writeToolInputSchemas.snooze_work_item.parse(rawInput);
      const item = findWorkItemOrRefuse(state, input.workItemId);
      assertAllowed(actionsFor(item), "snooze");
      const until = Date.parse(input.until);
      if (until <= now)
        throw new AgentToolRefusal("Pick a time in the future.");
      const undoToken = localStore.snoozeWorkItem(item._id, until);
      return outcome(item._id, undoToken, "Snoozed a backlog item");
    }

    case "archive_work_item": {
      const input = writeToolInputSchemas.archive_work_item.parse(rawInput);
      const item = findWorkItemOrRefuse(state, input.workItemId);
      assertAllowed(actionsFor(item), "archive");
      const undoToken = localStore.archiveWorkItem(item._id);
      return outcome(item._id, undoToken, "Archived a backlog item");
    }

    case "unsettle_work_item":
    case "unsnooze_work_item":
    case "restore_work_item": {
      const input = writeToolInputSchemas[tool].parse(rawInput);
      const item = findWorkItemOrRefuse(state, input.workItemId);
      const actionId =
        tool === "unsettle_work_item"
          ? "unsettle"
          : tool === "unsnooze_work_item"
            ? "unsnooze"
            : "restore";
      assertAllowed(actionsFor(item), actionId);
      const { undoToken } = localStore.runWithUndo(() => {
        if (tool === "unsettle_work_item")
          localStore.unsettleWorkItem(item._id);
        else if (tool === "unsnooze_work_item")
          localStore.unsnoozeWorkItem(item._id);
        else localStore.restoreWorkItem(item._id);
      });
      const label = {
        unsettle_work_item: "Unsettled a backlog item",
        unsnooze_work_item: "Ended a snooze",
        restore_work_item: "Restored a backlog item",
      }[tool];
      return outcome(item._id, undoToken, label);
    }
  }
}
```

```ts
import { randomUUID } from "node:crypto";
import type {
  AgentActivity,
  AgentClientRef,
  AgentError,
  AgentQuestion,
  AgentSession,
  AgentsSnapshot,
} from "../../../packages/shared/agent-tools.ts";

/**
 * Agent sessions, questions, the activity list and recent errors. All of it
 * lives in memory: restarting Ajour clears it. See the spec's "Sessions and
 * questions" section for the deadline rules.
 */

const MINUTE = 60_000;
const DEADLINE_MARGIN = 1.25;
const MIN_WINDOW_MS = 2 * MINUTE;
const MAX_WINDOW_MS = 4 * 60 * MINUTE;
/** The window a stalled session gets back when it reports again. */
const REVIVAL_MINUTES = 5;
const MAX_ENDED_SESSIONS = 50;
const MAX_ACTIVITY = 200;
const MAX_ERRORS = 50;

/** An estimate plus 25%, at least 2 minutes and at most 4 hours. */
export function sessionWindowMs(minutes: number) {
  return Math.min(
    MAX_WINDOW_MS,
    Math.max(MIN_WINDOW_MS, Math.round(minutes * MINUTE * DEADLINE_MARGIN)),
  );
}

/** A session or question call Ajour refuses. The message goes to the agent. */
export class AgentSessionError extends Error {
  constructor(message: string) {
    super(message);
    this.name = "AgentSessionError";
  }
}

export type WaitForAnswerResult =
  | { status: "answered"; answer: string }
  | { status: "waiting" }
  | { status: "withdrawn" };

interface AgentSessionsOptions {
  now?: () => number;
  createId?: () => string;
  /** Runs after every change, to publish the snapshot. */
  onChange?: () => void;
  /** Runs once when a session ends, for the `mcp.session_ended` event. */
  onEnded?: (session: AgentSession) => void;
}

const isOpen = (session: AgentSession) =>
  session.state === "active" || session.state === "stalled";
const isOpenQuestion = (question: AgentQuestion) =>
  question.answer === undefined && !question.withdrawn;

export class AgentSessions {
  private readonly sessions = new Map<string, AgentSession>();
  private readonly questions = new Map<string, AgentQuestion>();
  private readonly waiters = new Map<string, Set<() => void>>();
  private activity: AgentActivity[] = [];
  private errors: AgentError[] = [];
  private seenAt = 0;

  constructor(private readonly options: AgentSessionsOptions = {}) {}

  begin(
    client: AgentClientRef,
    input: { title: string; estimateMinutes: number },
  ): AgentSession {
    const now = this.now();
    const session: AgentSession = {
      id: this.createId(),
      client,
      title: input.title,
      state: "active",
      startedAt: now,
      deadlineAt: now + sessionWindowMs(input.estimateMinutes),
      messages: [],
    };
    this.sessions.set(session.id, session);
    this.pruneSessions();
    this.changed();
    return session;
  }

  update(
    client: AgentClientRef,
    input: { sessionId: string; message: string; extraMinutes?: number },
  ): AgentSession {
    const session = this.openSession(client, input.sessionId);
    const now = this.now();
    session.messages.push({ kind: "update", at: now, text: input.message });
    if (session.state === "stalled") {
      this.revive(session, input.extraMinutes ?? REVIVAL_MINUTES);
    } else if (input.extraMinutes !== undefined) {
      const extra = sessionWindowMs(input.extraMinutes);
      if (session.pausedRemainingMs !== undefined) {
        session.pausedRemainingMs += extra;
      } else {
        session.deadlineAt = Math.max(session.deadlineAt ?? now, now) + extra;
      }
    }
    this.changed();
    return session;
  }

  end(
    client: AgentClientRef,
    input: {
      sessionId: string;
      outcome: "done" | "failed" | "cancelled";
      summary: string;
    },
  ): AgentSession {
    const session = this.openSession(client, input.sessionId);
    const now = this.now();
    session.state = input.outcome;
    session.endedAt = now;
    session.deadlineAt = undefined;
    session.pausedRemainingMs = undefined;
    session.messages.push({
      kind: "end",
      at: now,
      outcome: input.outcome,
      summary: input.summary,
    });
    for (const question of this.questions.values()) {
      if (question.sessionId === session.id && isOpenQuestion(question)) {
        question.withdrawn = true;
        this.wake(question.id);
      }
    }
    this.options.onEnded?.(session);
    this.changed();
    return session;
  }

  ask(
    client: AgentClientRef,
    input: { question: string; choices?: string[]; sessionId?: string },
  ): AgentQuestion {
    const now = this.now();
    const session = input.sessionId
      ? this.openSession(client, input.sessionId)
      : undefined;
    const question: AgentQuestion = {
      id: this.createId(),
      client,
      ...(session ? { sessionId: session.id } : {}),
      text: input.question,
      ...(input.choices ? { choices: input.choices } : {}),
      askedAt: now,
    };
    if (session) {
      if (session.state === "stalled") this.revive(session, REVIVAL_MINUTES);
      if (session.pausedRemainingMs === undefined) {
        session.pausedRemainingMs = Math.max(
          0,
          (session.deadlineAt ?? now) - now,
        );
        session.deadlineAt = undefined;
      }
      session.messages.push({
        kind: "question",
        at: now,
        questionId: question.id,
        text: question.text,
        ...(question.choices ? { choices: question.choices } : {}),
      });
    }
    this.questions.set(question.id, question);
    this.changed();
    return question;
  }

  /** The user's answer, from the agent panel. */
  answer(questionId: string, text: string): AgentQuestion {
    const question = this.questions.get(questionId);
    if (!question || !isOpenQuestion(question)) {
      throw new AgentSessionError("This question is no longer open.");
    }
    const now = this.now();
    question.answer = text;
    question.answeredAt = now;
    const session = question.sessionId
      ? this.sessions.get(question.sessionId)
      : undefined;
    if (session) {
      session.messages.push({ kind: "answer", at: now, questionId, text });
      const stillWaiting = [...this.questions.values()].some(
        (other) => other.sessionId === session.id && isOpenQuestion(other),
      );
      if (!stillWaiting && session.pausedRemainingMs !== undefined) {
        session.deadlineAt = now + session.pausedRemainingMs;
        session.pausedRemainingMs = undefined;
      }
    }
    this.wake(questionId);
    this.changed();
    return question;
  }

  /** Holds until the question is answered or withdrawn, or `timeoutMs` passes. */
  async waitForAnswer(
    client: AgentClientRef,
    questionId: string,
    timeoutMs: number,
  ): Promise<WaitForAnswerResult> {
    const question = this.questions.get(questionId);
    if (!question || question.client.id !== client.id) {
      throw new AgentSessionError(`No question has the id ${questionId}.`);
    }
    if (isOpenQuestion(question)) {
      await new Promise<void>((resolve) => {
        const waiters = this.waiters.get(questionId) ?? new Set();
        const done = () => {
          clearTimeout(timer);
          waiters.delete(done);
          resolve();
        };
        const timer = setTimeout(done, timeoutMs);
        waiters.add(done);
        this.waiters.set(questionId, waiters);
      });
    }
    if (question.answer !== undefined) {
      return { status: "answered", answer: question.answer };
    }
    return question.withdrawn ? { status: "withdrawn" } : { status: "waiting" };
  }

  /** Marks active sessions past their deadline as stalled. */
  tick() {
    const now = this.now();
    let changed = false;
    for (const session of this.sessions.values()) {
      if (
        session.state === "active" &&
        session.deadlineAt !== undefined &&
        now > session.deadlineAt
      ) {
        session.state = "stalled";
        changed = true;
      }
    }
    if (changed) this.changed();
  }

  recordActivity(
    client: AgentClientRef,
    entry: Pick<AgentActivity, "tool" | "action" | "objectId" | "objectTitle">,
  ) {
    const session = [...this.sessions.values()]
      .reverse()
      .find(
        (candidate) => candidate.client.id === client.id && isOpen(candidate),
      );
    this.activity = [
      {
        at: this.now(),
        client,
        ...(session ? { sessionId: session.id } : {}),
        ...entry,
      },
      ...this.activity,
    ].slice(0, MAX_ACTIVITY);
    this.changed();
  }

  recordError(message: string, client?: AgentClientRef) {
    this.errors = [
      { at: this.now(), ...(client ? { client } : {}), message },
      ...this.errors,
    ].slice(0, MAX_ERRORS);
    this.changed();
  }

  /** The user opened the panel: earlier errors and failures are seen. */
  markSeen() {
    this.seenAt = this.now();
    this.changed();
  }

  snapshot(): AgentsSnapshot {
    return {
      sessions: [...this.sessions.values()].reverse(),
      openQuestions: [...this.questions.values()]
        .filter(isOpenQuestion)
        .reverse(),
      activity: this.activity,
      errors: this.errors,
      seenAt: this.seenAt,
    };
  }

  /** Releases waiting agents when the API stops. */
  close() {
    for (const questionId of this.waiters.keys()) this.wake(questionId);
  }

  private openSession(client: AgentClientRef, sessionId: string) {
    const session = this.sessions.get(sessionId);
    if (!session || session.client.id !== client.id || !isOpen(session)) {
      throw new AgentSessionError(
        `No open session has the id ${sessionId}. Call begin_session.`,
      );
    }
    return session;
  }

  private revive(session: AgentSession, minutes: number) {
    session.state = "active";
    session.deadlineAt = this.now() + sessionWindowMs(minutes);
  }

  private wake(questionId: string) {
    for (const done of this.waiters.get(questionId) ?? []) done();
    this.waiters.delete(questionId);
  }

  private pruneSessions() {
    const ended = [...this.sessions.values()].filter(
      (session) => !isOpen(session),
    );
    for (const session of ended.slice(
      0,
      Math.max(0, ended.length - MAX_ENDED_SESSIONS),
    )) {
      this.sessions.delete(session.id);
      for (const [questionId, question] of this.questions) {
        if (question.sessionId === session.id)
          this.questions.delete(questionId);
      }
    }
  }

  private now() {
    return (this.options.now ?? Date.now)();
  }

  private createId() {
    return (this.options.createId ?? randomUUID)();
```

```ts
import type { AgentsSnapshot } from "@ajour/shared/agent-tools";

/**
 * The agent indicator's one state, the most urgent across all sessions:
 * needs input, then error, then failed, then active, then idle. Opening the
 * panel (`seenAt`) clears past errors and failures. A stalled session or a
 * lost API connection keeps its state until it recovers.
 */

export type AgentIndicatorState =
  "hidden" | "idle" | "active" | "needs-input" | "failed" | "error";

export interface AgentIndicator {
  state: AgentIndicatorState;
  label: string;
}

export function getAgentIndicator({
  mcpEnabled,
  bridgeStatus,
  snapshot,
}: {
  mcpEnabled: boolean;
  bridgeStatus: "off" | "connecting" | "connected" | "disconnected";
  snapshot: AgentsSnapshot | null;
}): AgentIndicator {
  if (!mcpEnabled) return { state: "hidden", label: "" };

  const questions = snapshot?.openQuestions.length ?? 0;
  if (questions > 0) {
    return {
      state: "needs-input",
      label: questions === 1 ? "Needs input" : `${questions} questions`,
    };
  }

  const seenAt = snapshot?.seenAt ?? 0;
  if (bridgeStatus === "disconnected") {
    return { state: "error", label: "Can't reach Ajour's API" };
  }
  if (snapshot?.errors.some((error) => error.at > seenAt)) {
    return { state: "error", label: "Error" };
  }

  const sessions = snapshot?.sessions ?? [];
  if (sessions.some((session) => session.state === "stalled")) {
    return { state: "failed", label: "Stalled" };
  }
  if (
    sessions.some(
      (session) =>
        session.state === "failed" && (session.endedAt ?? 0) > seenAt,
    )
  ) {
    return { state: "failed", label: "Failed" };
  }

  const active = sessions.filter(
    (session) => session.state === "active",
  ).length;
  if (active > 0) {
    return {
      state: "active",
      label: active === 1 ? "Working" : `${active} working`,
    };
  }
  return { state: "idle", label: "Agents idle" };
}
```

```ts
import { useSyncExternalStore } from "react";
import type { AgentsSnapshot } from "@ajour/shared/agent-tools";
import type { McpBridgeStatus } from "@/lib/mcp-bridge";

/** The bridge's status for the agent indicator. `off` while MCP is off. */
export type AgentBridgeStatus = McpBridgeStatus | "off";

interface AgentBridgeState {
  status: AgentBridgeStatus;
  /** Null until the API sends the first snapshot. */
  snapshot: AgentsSnapshot | null;
  panelOpen: boolean;
}

let state: AgentBridgeState = {
  status: "off",
  snapshot: null,
  panelOpen: false,
};
const listeners = new Set<() => void>();

function update(patch: Partial<AgentBridgeState>) {
  state = { ...state, ...patch };
  listeners.forEach((listener) => listener());
}

export function setAgentBridgeStatus(status: AgentBridgeStatus) {
  if (state.status !== status) update({ status });
}

export function setAgentsSnapshot(snapshot: AgentsSnapshot) {
  update({ snapshot });
}

export function openAgentPanel() {
  update({ panelOpen: true });
}

export function closeAgentPanel() {
  update({ panelOpen: false });
}

export function getAgentBridgeState() {
  return state;
}

export function useAgentBridgeState(): AgentBridgeState {
  return useSyncExternalStore(
    (listener) => {
      listeners.add(listener);
      return () => listeners.delete(listener);
    },
    () => state,
  );
}
```

```tsx
import { useEffect } from "react";
import type { AgentsSnapshot } from "@ajour/shared/agent-tools";
import { showActionToast } from "@/components/ui/toast";
import { connectMcpBridge } from "@/lib/mcp-bridge";
import { useMcpSettings } from "@/lib/mcp-settings";
import {
  getAgentBridgeState,
  openAgentPanel,
  setAgentBridgeStatus,
  setAgentsSnapshot,
} from "@/features/agents/agent-bridge-state";
import { runAgentToolCall } from "@/features/agents/agent-tool-runner";

const QUESTION_PREVIEW_LENGTH = 80;

/** Shows a toast for each question the previous snapshot did not have. */
function announceNewQuestions(next: AgentsSnapshot) {
  const known = new Set(
    getAgentBridgeState().snapshot?.openQuestions.map(
      (question) => question.id,
    ),
  );
  for (const question of next.openQuestions) {
    if (known.has(question.id)) continue;
    const text =
      question.text.length > QUESTION_PREVIEW_LENGTH
        ? `${question.text.slice(0, QUESTION_PREVIEW_LENGTH - 1)}…`
        : question.text;
    showActionToast({
      title: `${question.client.name} asks: ${text}`,
      actionLabel: "Answer",
      onAction: openAgentPanel,
    });
  }
}

/** Keeps the MCP bridge open while MCP is on. Mount once, in the app shell. */
export function AgentBridgeHost() {
  const settings = useMcpSettings();
  const enabled = settings.kind === "ready" && settings.settings.enabled;

  useEffect(() => {
    if (!enabled) {
      setAgentBridgeStatus("off");
      return;
    }
    return connectMcpBridge({
      runToolCall: runAgentToolCall,
      onStatus: setAgentBridgeStatus,
      onAgents: (snapshot) => {
        announceNewQuestions(snapshot);
        setAgentsSnapshot(snapshot);
      },
    });
  }, [enabled]);

  return null;
}
```

`apps/web/src/features/agents/agent-panel.tsx`:

```tsx
import { useEffect, useState } from "react";
import type { AgentQuestion, AgentSession } from "@ajour/shared/agent-tools";
import { Button } from "@/components/ui/button";
import {
  Sheet,
  SheetContent,
  SheetHeader,
  SheetTitle,
} from "@/components/ui/sheet";
import { Tabs, TabsContent, TabsList, TabsTrigger } from "@/components/ui/tabs";
import { Textarea } from "@/components/ui/textarea";
import { answerAgentQuestion, markAgentsSeen } from "@/lib/app-api";
import { useIsNarrowView } from "@/lib/use-narrow-view";
import {
  closeAgentPanel,
  setAgentsSnapshot,
  useAgentBridgeState,
} from "@/features/agents/agent-bridge-state";

/**
 * The agent panel: sessions as chats, open questions, the activity list and
 * errors. It takes sessions as generic data, so later LLM plugins can reuse it.
 */

const time = (at: number) =>
  new Date(at).toLocaleTimeString([], { hour: "2-digit", minute: "2-digit" });

function QuestionForm({ question }: { question: AgentQuestion }) {
  const [text, setText] = useState("");
  const [error, setError] = useState<string | null>(null);
  const send = async (answer: string) => {
    setError(null);
    try {
      setAgentsSnapshot(await answerAgentQuestion(question.id, answer));
    } catch (cause) {
      setError(cause instanceof Error ? cause.message : "Unknown error");
    }
  };

  return (
    <div className="flex flex-col gap-2 rounded-[var(--radius-md)] border border-[var(--warning)] p-3">
      <p className="text-sm">
        <span className="font-medium">{question.client.name}</span> asks:{" "}
        {question.text}
      </p>
      {question.choices ? (
        <div className="flex flex-wrap gap-2">
          {question.choices.map((choice) => (
            <Button
              key={choice}
              variant="outline"
              size="sm"
              onClick={() => void send(choice)}
            >
              {choice}
            </Button>
          ))}
        </div>
      ) : null}
      <form
        className="flex flex-col gap-2"
        onSubmit={(event) => {
          event.preventDefault();
          if (text.trim()) void send(text.trim());
        }}
      >
        <Textarea
          aria-label="Your answer"
          value={text}
          onChange={(event) => setText(event.target.value)}
        />
        <Button type="submit" size="sm" disabled={!text.trim()}>
          Send
        </Button>
      </form>
      {error ? <p className="text-xs text-destructive">{error}</p> : null}
    </div>
  );
}

function SessionChat({ session }: { session: AgentSession }) {
  return (
    <ol className="flex flex-col gap-1 text-sm">
      {session.messages.map((message, index) => (
        <li key={index} className="flex gap-2">
          <span className="font-mono text-xs text-muted-foreground">
            {time(message.at)}
          </span>
          <span>
            {message.kind === "update" && message.text}
            {message.kind === "question" && `Asked: ${message.text}`}
            {message.kind === "answer" && `You answered: ${message.text}`}
            {message.kind === "end" &&
              `Ended ${message.outcome}: ${message.summary}`}
          </span>
        </li>
      ))}
    </ol>
  );
}

export function AgentPanel() {
  const { snapshot, panelOpen } = useAgentBridgeState();
  const narrow = useIsNarrowView();

  // Opening the panel marks earlier errors and failures as seen.
  useEffect(() => {
    if (!panelOpen) return;
    void markAgentsSeen()
      .then(setAgentsSnapshot)
      .catch(() => undefined);
  }, [panelOpen]);

  const sessions = snapshot?.sessions ?? [];
  const questions = snapshot?.openQuestions ?? [];

  return (
    <Sheet
      open={panelOpen}
      onOpenChange={(open) => (open ? undefined : closeAgentPanel())}
    >
      <SheetContent
        side={narrow ? "bottom" : "right"}
        className="flex flex-col gap-3 p-4"
      >
        <SheetHeader>
          <SheetTitle>Agents</SheetTitle>
        </SheetHeader>
        <Tabs defaultValue="sessions" className="flex min-h-0 flex-1 flex-col">
          <TabsList>
            <TabsTrigger value="sessions">Sessions</TabsTrigger>
            <TabsTrigger value="activity">Activity</TabsTrigger>
          </TabsList>
          <TabsContent
            value="sessions"
            className="flex flex-col gap-3 overflow-y-auto"
          >
            {questions
              .filter((question) => !question.sessionId)
              .map((question) => (
                <QuestionForm key={question.id} question={question} />
              ))}
            {sessions.length === 0 && questions.length === 0 ? (
              <p className="text-sm text-muted-foreground">
                No agent sessions yet.
              </p>
            ) : null}
            {sessions.map((session) => (
              <section key={session.id} className="flex flex-col gap-2">
                <header className="flex items-baseline justify-between gap-2">
                  <h3 className="text-sm font-medium">{session.title}</h3>
                  <span className="text-xs text-muted-foreground">
                    {session.client.name} · {session.state}
                  </span>
                </header>
                <SessionChat session={session} />
                {questions
                  .filter((question) => question.sessionId === session.id)
                  .map((question) => (
                    <QuestionForm key={question.id} question={question} />
                  ))}
              </section>
            ))}
          </TabsContent>
          <TabsContent
            value="activity"
            className="flex flex-col gap-1 overflow-y-auto text-sm"
          >
            {(snapshot?.errors ?? []).map((error) => (
              <p
                key={`error-${error.at}-${error.message}`}
                className="text-destructive"
              >
                {time(error.at)} {error.client ? `${error.client.name}: ` : ""}
                {error.message}
              </p>
            ))}
            {(snapshot?.activity ?? []).map((entry) => (
              <p key={`${entry.at}-${entry.objectId}`}>
                <span className="font-mono text-xs text-muted-foreground">
                  {time(entry.at)}
                </span>{" "}
                {entry.client.name}: {entry.action} · {entry.objectTitle}
              </p>
            ))}
          </TabsContent>
        </Tabs>
      </SheetContent>
    </Sheet>
  );
}
```
