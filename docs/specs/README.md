# Design specs

These specs were written before Ajour moved its planning to the issue tracker.
They are frozen: they record what was decided at the time, and the code that
cites them still points here. Do not add new files.

New specs are GitHub issues published with the `to-spec` skill, and their
implementation tickets come from `to-tickets`. Lasting decisions go in
[`docs/adr/`](../adr/), and current behavior lives in
[`docs/agents/ux-spec.md`](../agents/ux-spec.md) and
[`docs/agents/architecture.md`](../agents/architecture.md).

The implementation plans that went with these specs were removed when their
work shipped. Git history keeps them.
