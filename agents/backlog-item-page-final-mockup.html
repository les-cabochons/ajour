Theme
  • The newest 5 comments show. “Show earlier comments” loads 20 more each time.
  • The editor stays pinned to the bottom of the window while the thread scrolls. CodeMirror loads on first focus.
  • Images show inline and load as they scroll into view. SVG and other files show as file chips.
  • A pasted file stays on this machine until you click Comment.
  • Typing @ searches people through the plugin. The mention is stored as [@Ana Silva](mention:…) and shown as a chip.
  • Edit and delete sit in the “…” menu of your own comments. Deleting waits for the Undo toast to close.
