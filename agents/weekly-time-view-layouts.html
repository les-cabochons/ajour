Product rulesDay first. Two useful Week tools.

The Time route always opens in Day because timer work is HarDay’s core loop. A dedicated Week action opens the secondary desktop workspace; a clear “Day” return action replaces the competing Day/Week segmented control. Capacity targets and both warning preferences live in Settings. Below 1024px, Week controls disappear and the route falls back to Day.

One entry editorDay renders it inline; Week opens it in a modal. Duplicate, Duplicate to…, and Move to… live in the same action menu everywhere.
Submitted work can changeEditing or moving it clears the current submission state and marks the entry for resubmission. Copies are always unsubmitted.
Settings own warningsOver-target and under-target-on-submit warnings can be disabled independently.
