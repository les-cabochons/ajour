# Command palette

The command palette finds any task, backlog item, project or page, and runs any action, from the keyboard.

<Shot name="command-palette" alt="The command palette" />

Press <kbd>⌘</kbd> <kbd>K</kbd> to open it.

## Search

Type part of a name. Every word must match, and accents do not matter. Results include tasks, backlog items and projects, followed by actions and pages. A task also matches its project's name or code, and a synced backlog item its number, such as `1234`.

- Pick a **task** or a **backlog item** to see its actions, such as **New entry…**, **Snooze…** or **Settle**. A task's first action starts an entry on it, such as **Start Development (Client Atlas)**. Press <kbd>Backspace</kbd> in the empty field to go back.
- Pick an **action**, such as **New entry**, **Create project** or **Create task in…**, to run it. The palette shows each action's shortcut, so you learn them as you go.
- Pick a **page**, such as **Go to Backlog**, **Archived projects** or a settings page, to open it.

An action that does not apply now is greyed out with the reason, such as **Restore the task first**.

## Act on what you are looking at

When a row has focus, the palette opens on that row's actions first. For example, focus a backlog item, press <kbd>⌘</kbd> <kbd>K</kbd>, and type `snooze`. **Move up** and **Move down** are listed there too, for rows you can reorder.

Archived tasks and items do not show in results. Archived projects show after active ones.
