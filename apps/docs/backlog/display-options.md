# Display options

Display options change how the Backlog page groups, orders and shows items. Press **Display** at the top right of the Backlog page.

<Shot name="backlog-display" alt="The Display options popover" />

Ajour saves display options on this device. Ordering is shared with the sidebar, so both list items in the same order.

## Options

| Option                 | Values                                                                                   |
| ---------------------- | ---------------------------------------------------------------------------------------- |
| **Layout**             | List or board.                                                                           |
| **Grouping**           | **Workflow state** (default), **Priority**, **Project**, or **None** in the list layout. |
| **Swimlanes**          | On the board: **None** or **Project**.                                                   |
| **Ordering**           | **Custom** (default), **Priority**, **Created**, **Remaining estimate** or **Title**.    |
| **Done items**         | **Past week** (default), **All** or **None**.                                            |
| **Show settled items** | Shows settled items, marked **Settled**. On by default.                                  |
| **Show subitems**      | Shows subitems. On by default.                                                           |

## Custom order

With **Custom** ordering, drag items to put them in the order you want, or press <kbd>Alt</kbd> <kbd>↑</kbd> and <kbd>Alt</kbd> <kbd>↓</kbd>. The sidebar uses the same order.

With **Priority** ordering, the items of one priority level keep that same order. Drag an item within its group, or press <kbd>Alt</kbd> <kbd>↑</kbd> and <kbd>Alt</kbd> <kbd>↓</kbd>, to move it among the items of its level. It stops at the first and last item of the level, so its priority does not change. Subitems move the same way.

With the other orderings, you can only drag an item to another group.

## Display properties

Choose which details each row shows: **ID**, **Priority**, **Project**, **Estimate** and **Source state**. Source state is off by default.
