# Plugins

Plugins connect Ajour to the tools where your work lives. They run on your machine, in the desktop app.

## Official plugins

| Plugin       | What it does                                                   |
| ------------ | -------------------------------------------------------------- |
| Azure DevOps | Syncs work items into your backlog and writes estimates back.  |
| Jira         | Syncs Jira issues into your backlog and writes estimates back. |
| GitHub       | Lists the pull requests you wrote or were asked to review.     |
| Workday      | Maps projects and tasks to a Workday file. Coming soon.        |

## Install a plugin

Open **Settings › Plugins**, pick a plugin and press **Download**. Ajour installs it turned off, so you can activate it when you are ready to add a connection.

<Shot alt="The plugin catalog in Settings" />

::: info
Plugins need the desktop app. The web build shows the catalog but cannot install plugins.
:::
