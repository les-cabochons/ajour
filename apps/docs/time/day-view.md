# Day view

The Day view lists the entries of one day. It opens on today when you start Ajour.

<Shot alt="The Day view" />

## Move between days

| Key          | Action         |
| ------------ | -------------- |
| <kbd>T</kbd> | Go to today    |
| <kbd>[</kbd> | Previous day   |
| <kbd>]</kbd> | Next day       |
| <kbd>W</kbd> | Switch to Week |

## Edit an entry

Click a row to open it in the side panel. Change the hours, the task or the note, then press **Save** or <kbd>⌘</kbd> <kbd>Enter</kbd>.

::: tip
Press <kbd>Esc</kbd> to close the editor without saving.
:::

### Delete an entry

Right-click the row and choose **Delete**. An Undo toast shows for a few seconds.
