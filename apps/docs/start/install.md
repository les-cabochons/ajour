# Install Ajour

Ajour runs on macOS and Windows. Download the installer from the [GitHub releases page](https://github.com/les-cabochons/ajour/releases).

| Platform              | File                        |
| --------------------- | --------------------------- |
| macOS (Apple silicon) | `Ajour-<version>-arm64.dmg` |
| macOS (Intel)         | `Ajour-<version>-x64.dmg`   |
| Windows               | `Ajour-<version>-x64.exe`   |

::: warning Unsigned builds
The installers are not signed yet. macOS and Windows show a warning the first time you open Ajour.
:::

## Updates

Windows installs update in the background. On macOS, download the new version from the releases page.
