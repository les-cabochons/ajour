# UX walkthrough screenshots

Throwaway asset branch for [Screenshot walkthrough of every screen and state](https://github.com/les-cabochons/ajour/issues/9), part of the UX wayfinder map (issue #6). Never merged.

Captured on 2026-10-10 from `main` at `3fcbb6a`, web build (`just start`), light theme, with seeded local data. Viewports: 1440x900 (`w*`), 800x860 (`n800-*`) and 600x860 (`n600-*`).

To recapture, start the app with `just start` and run `node walk.cjs`. The script requires Playwright from the main checkout's `node_modules` and writes to `out/`.
